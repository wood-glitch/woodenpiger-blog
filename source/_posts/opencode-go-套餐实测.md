先给结论：**只要你在用 AI 写代码，OpenCode 的 Go 套餐基本是闭眼订的**。10 美元一个月，折合人民币 67 块左右，我那天晚上一个项目的消耗就把月费赚回来好几倍了。

<!-- more -->

## 一晚上到底烧了多少

那天晚上我写一个项目，数据扒下来是这样：

![CC Switch 用量统计：2.53 亿 token，99% 缓存命中，成本 $2.76](/images/e6fb9580ce3c873e91b2b80e7ac2436c.png)

- 真实消耗 token：**2.53 亿**
- 缓存命中率：**99.0%**
- 请求数：757 次
- 折算成本：**$2.76**

注意这里的 $2.76 是"按量计费等价成本"，不是真的又扣了我 2.76 美元——Go 套餐是包月额度制，实际扣的是那 5 小时的额度，而这 2.53 亿 token 只吃掉了 **7%**：

![OpenCode Go 额度：5 小时已用 7%，每周 3%，每月 1%](/images/e7ef0256984c66a6a77c1379f91deff0.png)

也就是说，一晚上这么高强度的连续输出，连一个 5 小时窗口的十分之一都没用完。缓存命中率能到 99% 是关键——同一个项目里反复读同一批文件、同一段上下文，绝大部分输入都走了缓存价，额度自然掉得慢。

## 二、价格和优惠规则

- 套餐价：**$10 / 月**，约合 **¥67**
- **周末使用 DeepSeek V4 Flash 是半价**：同样的额度能撑出双倍的活
- **非工作时间额度也是半价**

官方的"工作时间"定义是：

| 时间段 | 说明 |
| --- | --- |
| 周一 ~ 周五 08:00 – 12:00 | 全价 |
| 周一 ~ 周五 14:00 – 18:00 | 全价 |
| 其余时间（含周末、深夜、午休） | 半价 |

像我这种习惯晚上十点以后写东西的人，等于天天半价。图上那根柱状图的峰值全在 19:00 – 23:00，就是这个原因。

## 三、怎么订阅

订阅地址：

<https://opencode.ai/console/go>

支持**支付宝付款**，对没有外币信用卡的人很友好，扫码就能付，不用折腾虚拟卡。

订阅完之后，Go 套餐会作为一个 provider 出现在客户端里(我是用 CC Switch 统一管理的)，选 `OpenCode Go` 这个供应商，模型挑 `deepseek-v4.1-flash` 就能直接跑，不需要自己配 API Key 转发。

## 四、适合谁

- **天天写代码、懒得算 token 的**：包月额度制，不用担心某个下午把余额烧光
- **晚上/周末干活的学生和上班族**：半价时段命中率高，性价比直接翻倍
- **同时用 Codex、Claude Code、Kimi Code 的**：一个供应商全搞定，切换成本几乎为零
- **不想绑外币卡的人**：支付宝搞定

不太适合的：一个月只写两三次代码、用量极小的，免费额度或者按量付费更划算。

## 五、一点提醒

套餐额度是按 **5 小时窗口 + 每周 + 每月** 三层滚动的，短时间猛冲只会消耗 5 小时那一层，长期看更该盯"每月"那个百分比。另外缓存命中率对额度影响极大，写代码时尽量让 AI 在同一个项目上下文里连续工作，不要频繁新开会话——同样的活，命中率从 99% 掉到 50%，额度消耗会差出好几倍。

总之这个价格，我找不到不订的理由。
